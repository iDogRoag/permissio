# Release Checklist

- [ ] Run `npm ci`.
- [ ] Run `npm test`.
- [ ] Run `npm run build`.
- [ ] Run `npm run typecheck`.
- [ ] Run `npm pack --dry-run`.
- [ ] Run `permissio demo`.
- [ ] Run `permissio check examples/risky --show-snippets`.
- [ ] Update `CHANGELOG.md`.
- [ ] Tag release.
- [ ] Publish npm package.
- [ ] Create GitHub release.
- [ ] Post launch links.
