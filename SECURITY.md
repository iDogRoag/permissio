# Security Policy

permissio is a static analyzer. It does not call the GitHub API, require credentials, or execute workflow code.

## Reporting a Vulnerability

Please report security issues privately by opening a GitHub security advisory for the repository once available. If advisories are not enabled, email the maintainer listed on the GitHub profile.

Include:

- affected version or commit
- reproduction steps
- expected impact
- any workflow snippet needed to reproduce the issue

Please do not disclose exploitable issues publicly until there has been time to investigate and release a fix.

## Supported Versions

The latest released version is supported.
