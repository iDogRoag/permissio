# Launch Checklist

Use this as a practical checklist for a public Permissio launch.

- [x] Create GitHub repo.
- [x] Replace placeholder repo URLs.
- [ ] Publish npm package.
- [ ] Add repo topics.
- [ ] Record terminal demo GIF or screenshot.
- [ ] Post Show HN.
- [ ] Post to focused Reddit communities.
- [ ] Post to X, LinkedIn, Bluesky, and relevant Discords.
- [ ] Submit to developer launch sites.
- [ ] Ask early users for real workflow examples.

## Positioning

Main hook:

> Least privilege for GitHub Actions tokens in one command.

Short description:

> Permissio scans GitHub Actions workflows and recommends explicit job-level `GITHUB_TOKEN` permissions.

Do not frame Permissio as a full GitHub Actions security scanner or as proof that a workflow is safe.
